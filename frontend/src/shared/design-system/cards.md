# Cards

## Objectif

Les cartes permettent de présenter des contenus de manière claire, moderne et cohérente.

Elles sont utilisées pour les services, les réalisations et toute présentation d'information.

---

## Structure

Une carte peut contenir :

- Image (optionnelle)
- Icône (optionnelle)
- Titre
- Description
- Actions (optionnelles)

---

## Apparence

Fond :

- Blanc

Radius :

```css
--radius-lg
```

Ombre :

```css
--shadow-sm
```

Padding :

```css
--spacing-5
```

Bordure :

```css
--color-border
```

---

## États

Toutes les cartes possèdent les états suivants :

- Normal
- Hover

Au survol :

- légère élévation ;
- ombre renforcée ;
- animation douce.

---

## Responsive

Les cartes doivent :

- conserver des espacements cohérents ;
- s'adapter automatiquement à la largeur disponible ;
- rester lisibles sur mobile.

---

## Règles

- Une seule identité graphique.
- Les couleurs proviennent exclusivement du Design System.
- Aucun style inline.
- Les cartes restent sobres afin de mettre en valeur le contenu.
