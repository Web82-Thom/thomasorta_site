# Icons

## Objectif

Les icônes améliorent la compréhension de l'interface sans remplacer le texte.

Elles doivent rester sobres, cohérentes et discrètes.

---

## Bibliothèque retenue

Le projet utilise :

React Icons

Aucune autre bibliothèque d'icônes n'est prévue pour la V1.

---

## Taille

Petite

16 px

Normale

20 px

Grande

24 px

Très grande

32 px

---

## Couleurs

Les icônes utilisent uniquement les couleurs du Design System.

Exemples :

- Bleu lagon
- Or
- Blanc
- Couleur du texte

---

## Utilisation

Les icônes servent notamment à représenter :

- Téléphone
- Email
- Localisation
- GitHub
- LinkedIn
- Site Web
- Télécharger
- Menu
- Fermer
- Flèche
- Contact

---

## Règles

- Toujours accompagner une icône importante d'un texte.
- Ne jamais utiliser une icône seule lorsqu'elle peut créer une ambiguïté.
- Les tailles restent cohérentes sur l'ensemble du site.
- Les couleurs proviennent exclusivement du Design System.

---

## Décision validée

Bibliothèque retenue :

React Icons

Elle sera utilisée sur l'ensemble du projet afin de garantir :

- une cohérence visuelle ;
- une maintenance simplifiée ;
- une seule dépendance pour toutes les icônes ;
- une intégration native avec React.
