# Typography

## Objectif

La typographie doit transmettre une image moderne, professionnelle et sobre.

Le site privilégie la lisibilité sur tous les supports.

---

## Police principale

Police retenue :

Inter

Famille CSS :

```css
font-family:
  "Inter",
  system-ui,
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  sans-serif;
```

---

## Règles

- Une seule famille de police.
- Hiérarchie constante.
- Pas de tailles arbitraires.
- Pas de couleurs différentes selon les pages.
- Les variables CSS définissent l'ensemble de la typographie.
