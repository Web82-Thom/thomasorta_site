# Animations

## Objectif

Les animations doivent améliorer l'expérience utilisateur sans distraire.

Elles doivent être fluides, discrètes et apporter un retour visuel naturel.

La priorité est donnée à la simplicité et aux performances.

---

## Principes

Les animations doivent :

- être courtes ;
- être cohérentes sur tout le site ;
- ne jamais ralentir la navigation ;
- respecter les préférences d'accessibilité des utilisateurs.

---

## Durées

Très rapide

150 ms

Rapide

200 ms

Normale

300 ms

Lente

500 ms

---

## Animations autorisées

### Hover

- changement de couleur ;
- légère élévation ;
- légère ombre.

---

### Boutons

- transition de couleur ;
- transition d'ombre ;
- légère réduction ou agrandissement (maximum 2%).

---

### Cartes

Au survol :

- légère élévation ;
- ombre renforcée ;
- animation fluide.

---

### Navigation

- apparition douce ;
- soulignement animé des liens actifs.

---

### Apparition des sections

Les sections peuvent apparaître progressivement lors du défilement.

Les animations restent discrètes.

---

## Animations interdites

Ne pas utiliser :

- animations permanentes ;
- clignotements ;
- rotations inutiles ;
- effets 3D excessifs ;
- zoom important ;
- animations longues.

---

## Performances

Les animations privilégient :

- opacity
- transform

Éviter d'animer :

- width
- height
- top
- left

afin de conserver de bonnes performances.

---

## Accessibilité

Le projet devra respecter la préférence utilisateur :

prefers-reduced-motion

Les animations importantes devront pouvoir être réduites ou désactivées.

---

## Décisions validées

- Animations sobres.
- Transitions courtes.
- Priorité aux performances.
- Respect de l'accessibilité.
- Cohérence sur l'ensemble du site.
